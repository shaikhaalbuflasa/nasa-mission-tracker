# NASA Mission Tracker

## Project Idea

NASA Mission Tracker is a simple web-based tool designed to help users explore and track NASA space missions. The project provides information about different missions, including their names, descriptions, and current status.

The tool can help NASA-related education and organization by making mission information easier to view and understand.

## Technologies and Tools

- HTML
- CSS
- JavaScript
- GitHub
- GitHub Issues
- GitHub Projects

## How to Run the Project

1. Download or clone the repository from GitHub.
2. Open the project folder.
3. Open the `index.html` file in a web browser.
4. Use the application to explore NASA missions.

## Project Features

- View NASA missions
- Read mission descriptions
- Check mission status
- Simple and user-friendly interface
